
# Anusha L - Developer Portfolio

## Overview
This is a responsive, semantic, and SVG-only portfolio website of **Anusha L**, a Full Stack Developer with 6+ years of experience in building secure, scalable applications. The design is lightweight, modern, and easy to customize.

## Features
- **Semantic HTML5 Structure**: `header`, `nav`, `main`, `section`, `article`, `footer`
- **Responsive layout**: CSS Grid for cards, Flexbox for navigation and footer
- **SVG-only visuals**: No external images required
- **Accessible design**: Skip link, descriptive headings, focus states
- **Sections**:
  - Hero: Name, tagline, CTA buttons
  - Skills: Core stack, tools, front-end visualization
  - Projects: 6 major projects with descriptions
  - About: Professional summary, certifications
  - Contact: Email, LinkedIn, CV download

## Tech Stack
- **HTML5**
- **CSS3** (Flexbox + Grid)
- **SVG graphics**
- **Responsive design principles**

## How to Use
1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Customize:
   - Update email and LinkedIn links in the **Contact** section.
   - Replace placeholder CV link with your actual resume.
   - Modify colors in `style.css` under `:root` variables.
   - Add or remove projects by editing `.work-card` blocks.
